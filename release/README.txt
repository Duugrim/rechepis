РЕЧЕПИСЬ
========

Программа для голосовых записей по теме: вы говорите, она сама режет речь на куски по паузам,
чистит звук и превращает его в текст. Всё работает на вашем компьютере, голос никуда не отправляется.

Ничего устанавливать не нужно: Python и все библиотеки уже внутри.


КАК ЗАПУСТИТЬ
-------------
1. Распакуйте архив целиком в любую папку, куда можно писать (например, в «Документы»).
   Не запускайте программу из окна архива и не кладите её в Program Files.
2. Дважды щёлкните «Start Rechepis.bat».
3. Через несколько секунд в браузере откроется страница программы. Чёрное окно рядом — это сама
   программа: пока вы работаете, его нужно оставить открытым. Закрыли окно — программа остановилась.
4. Первый раз программа предложит скачать модель распознавания (около 430 МБ, нужен интернет,
   делается один раз). После этого интернет не нужен.

Микрофон: браузер спросит разрешение, нажмите «Разрешить». Он работает только на адресе
http://127.0.0.1:8765, на который вас приведёт программа.


ГДЕ ЛЕЖАТ ВАШИ ДАННЫЕ
---------------------
Всё, что вы записали, лежит в папке «data» рядом с программой:
  data\recordings   записи, звук и тексты
  data\models       скачанная модель
  data\config.json  настройки

Как обновиться: распакуйте новую версию в другую папку и перенесите в неё папку «data» целиком
(до первого запуска). Как удалить: просто удалите папку программы.


ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
------------------------
«Windows защитила ваш компьютер» — программа пока не подписана цифровой подписью. Нажмите
«Подробнее» → «Выполнить в любом случае». Чтобы не видеть это предупреждение для каждого файла,
перед распаковкой щёлкните по архиву правой кнопкой → «Свойства» → отметьте «Разблокировать».

«Port 8765 is already in use» — порт занят другой программой. Закройте её или запустите на другом
порту: откройте командную строку в папке программы и выполните две команды
    set RECHEPIS_PORT=8800
    ".\Start Rechepis.bat"
(тогда страница будет по адресу http://127.0.0.1:8800).

Страница не открылась сама — откройте в браузере http://127.0.0.1:8765 вручную.

Модель не скачивается — проверьте интернет и повторите: скачивание продолжится с того места,
где оборвалось.

Видеокарта не используется: в этой сборке распознавание идёт на процессоре. На современном
процессоре расшифровка идёт заметно быстрее, чем длится речь.
